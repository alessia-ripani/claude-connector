Privacy Policy

Claude Marketing Connector · Last updated September 16, 2026

What this app is

Claude Marketing Connector is a personal tool used only by its owner. It is not offered to anyone else.

What data it accesses

With the owner's permission, granted through Google sign-in, the app reads reporting data from the owner's own Google Ads, Google Analytics and Google Search Console accounts. Access is read-only. The app cannot change anything in those accounts.

How data is used

Data is used only to answer the owner's own questions about marketing performance. It is not sold, shared with third parties, or used for advertising.

Storage

The Google sign-in credentials are stored only on the owner's own computer. Report data is fetched when requested and is not kept in any separate database.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through github.com/alessia-ripani.
